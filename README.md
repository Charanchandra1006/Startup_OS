# Startup_OS

An AI-native operating system for early-stage companies that coordinates specialized AI agents across finance, hiring, legal, engineering, and go-to-market.

## Getting Started

### Prerequisites
- Node.js (v20+)
- Python (3.11+)
- Docker (Optional)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Charanchandra1006/Startup_OS.git
   cd Startup_OS
   ```

2. **Set up the environment:**
   Copy the `.env.example` file to `.env` and populate your secrets:
   ```bash
   cp .env.example .env
   ```

3. **Install Dependencies:**
   Navigate into the web directory and install frontend dependencies:
   ```bash
   cd apps/web
   npm install
   ```

### Running Locally
To run the web dashboard locally, execute:
```bash
npm run dev
```

The application will be accessible at http://localhost:3000.
